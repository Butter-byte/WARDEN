PART 2 - mobility (h1 roams s1 -> s2 and keeps VLAN 10)
  mininet> py net.configLinkStatus('h1', 's1', 'down')
  mininet> py net.configLinkStatus('h1', 's2', 'up')
  mininet> h1 ip addr flush dev h1-eth0
  mininet> h1 ip addr add 10.0.0.1/24 dev h1-eth1
  mininet> h1 ping -c 3 h3          works; dashboard shows h1 under s2
  reset:
  mininet> py net.configLinkStatus('h1', 's2', 'down')
  mininet> py net.configLinkStatus('h1', 's1', 'up')
  mininet> h1 ip addr flush dev h1-eth1
  mininet> h1 ip addr add 10.0.0.1/24 dev h1-eth0

PART 3 - detection and automatic quarantine (Modules 3+4)
Set SIM="/home/hrishig/ryu-venv/bin/python3 /home/hrishig/projects/sdn-vlan-project/detection/simulate_attacks.py"
  mininet> h3 $SIM arp-spoof     --iface h3-eth0 --victim-ip 10.0.0.1     -> arp-spoof, h3 quarantined
  mininet> h3 $SIM port-scan     --iface h3-eth0 --target-ip 10.0.0.1     -> port-scan, h3 quarantined
  mininet> h1 $SIM vlan-hop      --iface h1-eth0 --forged-vlan 20         -> vlan-violation, h1 quarantined
  mininet> h3 $SIM mac-flood     --iface h3-eth0                          -> mac-flood (alert only)
  mininet> h3 $SIM traffic-flood --iface h3-eth0 --target-ip 10.0.0.1     -> traffic-rate (alert only)
  mininet> h3 $SIM rogue-device  --iface h3-eth0                          -> unauthorized-device (alert only)
After a quarantine: h1 ping -c 2 h3 fails, h2 ping -c 2 h4 still works.
